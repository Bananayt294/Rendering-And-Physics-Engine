# Rendering-And-Physics-Engine
Custom 3D C++ rendering and physics engine built from scratch using MSVC, OpenGL 3.3, GLFW, and GLM. Combines GPU buffer management (VAO/VBO), custom Blinn-Phong shaders, and MVP camera matrices with a fixed-timestep physics solver handling Semi-Implicit Euler integration, rigid-body dynamics, AABB collision detection, and impulse-based resolution.
